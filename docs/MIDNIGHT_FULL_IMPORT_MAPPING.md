# Midnight full import: pre-implementation feature mapping

## Audit scope and evidence

**Decision:** generate a standalone `CompilationModel` from the pinned Solidity typed AST, not a copy, textual transformation, or splice of `Midnight.Contract.Midnight.spec`. Preserve explicit external/low-level trust boundaries, **not** erroneous handwritten behavior. Full generation is feasible with substantial frontend lowering; the existing three-function importer cannot produce it today. “Exactly” below means source behavior including storage, calls, ABI and revert order, not a proof of equivalence or byte-for-byte reproduction of the handwritten model.

Read-only source: `/home/claudine/Work/morpho-verity`. Output worktree: `/home/claudine/marketing/.context/midnight-full-import/repo`, initial HEAD `40e15e4b2910f0f29ff0e0e4e63131a316df5c27`. Solidity submodule HEAD verified clean at `a7c6da7e70cb216982f6c5d20b46f40b943e67e4`. Verity package is at the **repository root** `.lake/packages/verity`, verified clean at `760e9feb7161c6a4f26f8bad4bbcfb3950ff02ce` (matching `lake-manifest.json`). The new worktree submodules were uninitialized; none were changed.

Read https://veritylang.com/guides/solidity-to-verity.md. It recommends canonical `verity_contract` for hand-authored ports, explicit short-circuit control flow, checked arithmetic, structured storage, and localized trust boundaries. This task explicitly requests its lowered `CompilationModel` instead. The installed pin, not newer website features, determines available constructors.

**Executed audit extraction:** checksum-verified cached solc `0.8.34+commit.80d5c536` (`d40adc6f9fdbb22a97d32a02fa05688bf2ee7886affc48c9851b0afd4a726b39`) with standard JSON over sorted `src/**/*.sol`, optimizer 800, viaIR, Osaka, metadata bytecodeHash none; requested typed AST, storageLayout, ABI and methodIdentifiers. No compiler errors; **55 external/public ABI functions**. Input/output stayed in memory; no implementation, tests, proofs, build artifacts or upstream edits. Existing Foundry `out/Midnight.sol/Midnight.json` had **no storageLayout** and was not used as layout truth.

Abbreviations: **S** = `morpho-midnight/src/Midnight.sol`; **C** = `morpho-midnight-verity/Midnight/Contract.lean`; **I** = `src/interfaces/IMidnight.sol`; libraries/interfaces below are relative to `morpho-midnight/src`. `#n` denotes an actually extracted solc AST declaration ID for the pinned compilation input; IDs are provenance/checks, not names to match blindly. **Y** = mechanically source-derivable after implementing generic support; **B** = source-derivable but an explicit ABI/EVM/ECM trust boundary remains; **N** = no exact Solidity counterpart or a handwritten discrepancy: do not preserve as runtime behavior. These labels do not claim support is already implemented or proved.

## Confirmed discrepancies: source wins, not handwritten parity

1. **Constructor:** C2609–2611 assigns feeSetter/feeClaimer/tickSpacingSetter to deployer; S only assigns roleSetter and chainid, emits Constructor. This changes authorization immediately after deployment.
2. **Packed arrays:** C2447's collateral Uint256 elements and C2466's double mapping for default fees conflict with executed solc layout. Bounds getters/writers in C3815–4457/4491–5006 default to zero/no-op out of range; source fixed-array access panics.
3. **Missing touch:** withdraw, repay, supplyCollateral, withdrawCollateral and liquidate use toId in C3676/3744/5223/5249/5016 instead of source touchMarket. Market creation guards/defaults/code storage/events disappear.
4. **Missing events:** most EventsLib emissions absent; hybrid fixes only three setters. C Take event records payer before overriding it with buyerCallback (3570–3577), unlike S422/425. Buyer/seller UpdatePosition emissions occur outside conditional update branches (C3272/3330), unlike S379–380.
5. **Arithmetic and errors:** C widely uses wrapping `add/sub/mul`/stdlib mulDiv where Solidity operations are checked at actual operand widths. Packed writes do not replace CastOverflow or Panic. ClaimSettlementFee C2997 invents ConsumedAssets instead of source subtraction panic. `take` adds early `units<=uint128.max` and buyerAssets≥sellerAssets guards (3457/3482/3550), moving/changing failure behavior; source checks actual converted terms, not one blanket units guard.
6. **External observation order:** C take updates buyer/seller positions before gate calls (3506–3541), whereas S397–406 gates precede trade position writes S408–414. A static gate can observe changed state. `touchMarket` deploys before setting defaults in C3115 versus after in S786. Preserve source order rather than assuming commutativity.
7. **ERC20 semantics:** pinned SafeTransferLib uses custom errors and bubbles failures. C calls legacy-string modules; package ERC20.lean384–485 instead encodes string errors and substitutes generic transfer-reverted messages. Source performs zero-amount transfers too; C take skips them (3588–3597), changing code checks/reverts/callback effects.
8. **Collateral paths:** C supply/withdraw write collateral **after** external token interaction (5240–5241/5269–5270), source writes before interaction. C withdrawCollateral checks a one-collateral LLTV-only formula (5252–5256), omitting oracle prices and other active collateral; source calls isHealthy after writes.
9. **Liquidation loop:** source descends msb and remembers selected price in that loop; C snapshot ascends the calldata array and then unconditionally calls selected oracle again (5046–5050). Source can realize bad debt for inactive selected collateral with zero inputs without calling its oracle. C also adds an `inactive collateral` string guard and earlier selected-index check. These change calls, failure order and admissible behavior.
10. **Locks / helper ABI:** C replaces boolean save/restore by depth-based ECMs. It also exposes many C-only helpers, including an arbitrary `setCollateralAmount`, unless integration filters them; FunctionSpec's default is non-internal. Full generation must derive source visibility, not C names.
11. **Health order:** C isHealthy scans increasing array indices; source scans descending active bitmap. Equal arithmetic totals under assumptions do not establish exact external-call/revert trace equivalence, especially with mismatched public `market,id` inputs.
12. **Dynamic ABI / metadata:** toMarket C2781 declares Unit but an ECM returns code payload; scalar getters widen source uint128/uint32/uint8 and settlementFeeCbps returns a tuple. Generate actual Solidity ABI rather than treating current Verity metadata as truth.
13. **Stale trust prose:** `Proofs/TRUST_BOUNDARIES.md:13–18` claims legacy-string transfers are exact, contradicted by the pin; line27 conflates market parameter code storage with MarketState storage. It is evidence of intended low-level boundaries, not source semantics. Do not copy it into the generation policy unchanged.

This feature audit identifies concrete blockers, not an exhaustive equivalence proof of every handwritten Yul instruction. A separate semantic review may add findings; no existing proof claim is extended to the future full generated model.

## Minimal true AST-derived architecture (no handwritten templates)

1. **Pinned input envelope:** reuse existing importer's checksum/version/source-commit checks, sorted source collection and source hashes. Request AST + storageLayout + ABI + methodIdentifiers together. Reject dirty/missing inputs and compiler errors. Pin Verity too. Store canonical settings and input hash; AST IDs are meaningful only within this exact envelope.
2. **Typed declaration graph:** index every AST ID/source span; resolve imports, inheritance (Midnight implements IMidnight), free/library functions, using-for receiver bindings, member references, builtins and overloads. Compute closure from the full contract constructor/public functions and public-variable getters. Keep a source type graph (width/signedness, array dimensions, structs, mapping keys and storage/calldata/memory). Preserve lvalue identity/storage aliases, not textual substitutions.
3. **Source-semantic IR:** lower blocks/declarations/assignments/compound assignments/tuples/if/loops/returns/events/reverts/calls into scoped operations with source origins. Hoist evaluation into temporaries only where source order permits. Encode lazy booleans/ternaries as branches. Attach checked/unchecked arithmetic and narrowing semantics at each operation. Keep `_updatePosition`, `hasCredit` and real library helper boundaries; generated factoring is generic CFG/lvalue lowering, never protocol-named body templates.
4. **Solc-backed storage/ABI plans:** join storage declarations **and struct members** by astId; recurse types/base/key/value/encoding and validate every offset/width. Use arbitrary-precision integers for slots/constants (existing importer converts slots to JS Number; do not generalize that). Emit packed members/index dispatch from layout and input widths. Derive Market/Offer ABI offsets, dynamic encode/decode, output shapes and selectors from typed schemas. Explicit immutable policy is the sole synthetic persistent slot here; verify collision freedom and label it separately.
5. **Small reusable backend:** emit `Field`, `ErrorDef`, `EventDef`, `ConstructorSpec`, `FunctionSpec`, and one complete `CompilationModel`. Use the pinned model's native expressions/statements where adequate. Import genuine inline Yul through `YulImporter.importBlock`; implement generic ABI/call/memory/code-data mechanics as typed generated operations or generated ECMs with provenance and trust metadata. A special handler must match a structural/typed source construct, not a Solidity function name returning a pasted C body. No entire optimized-solc runtime hidden in one opaque ECM: that evades the requested model granularity.
6. **Explicit boundary policy:** permit only named necessary mechanisms: external oracle/gate/ratifier/token/callback behavior, dynamic ABI/memory, keccak, create2/code access, transient storage, delegatecall and panic encoding. Every boundary lists originating nodes, effects/frame, reason and assumed/unchecked status. “Same abstractions” means these categories and the immutable representation, **not** legacy errors, missing events or incorrect state ordering. No blanket escape, default value, skipped function, source-body hash → handwritten-model lookup, or `Contract.lean` import.
7. **Fail-closed completeness:** every reachable declaration, statement, expression, assembly opcode and data-layout node is lowered or causes a diagnostic with file/span/AST ID/type/unsupported feature. Compare exactly the 55-function source ABI set, return types/mutability, constructor, events, reachable errors, and storage plan. Report excluded unreachable periphery/ratifiers/priceToTick separately; they are external dependencies, not omissions in Midnight. Unknown new source constructs must break generation, not silently expand trust.
8. **Standalone integration contract:** replace `ArtifactConfig.fullArtifactSpec`'s `Midnight.spec` + AdminSliceHybrid path with the generated complete model only in the later implementation. Keep focused MidnightRCF/proofs separate. Deterministic output must contain its own fields/constructor/functions/events/errors and generated helper dependencies; no import/transitive reference to handwritten Midnight or imported-function replacement list. Stable source maps should cover operations as well as declarations. Only the generated model and generic pinned compiler/runtime modules are runtime dependencies.

**Practical blocking decisions before implementation:** choose an explicit narrow-output ABI metadata strategy compatible with the pin; commit to source-correct packed arrays; use generic typed dynamic ABI lowering rather than copying callback ECM templates; preserve source checked arithmetic and call order; accept immutable-at-reserved-slot as a labeled abstraction. If any cannot be implemented with this pin locally, stop with that concrete unsupported feature—do not call a handwritten hybrid a full import.
